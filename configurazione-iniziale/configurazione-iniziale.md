# Configurazione Iniziale

Premessa
-------
Per lo sviluppo locale utilizzo strumenti come Java, Maven, Python, 
IntelliJ IDEA e Visual Studio Code. Per la gestione di immagini e 
container su Windows 10/11 prediligo Docker Desktop: è semplice da 
usare e adatto a chi non vuole perdere tempo in complesse configurazioni.

Licenza
-------
Docker Desktop è gratuito solo per uso personale; per utilizzo aziendale 
è richiesta una licenza a pagamento. Personalmente lo uso per progetti 
personali, quindi posso installarlo e usarlo liberamente.

Alternativa
----------
Se in ambito aziendale si preferisce restare su Windows 11 senza 
configurare WSL con una distribuzione dedicata, una valida alternativa è 
Rancher Desktop. Offre funzionalità simili a Docker Desktop, è veloce e 
richiede pochissima configurazione. Alcuni plugin sono meno curati e 
l'interfaccia può mostrare bug occasionali: se questi limiti sono 
accettabili, Rancher Desktop rimane una buona scelta per lo sviluppo.
